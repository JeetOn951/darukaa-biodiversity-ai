# Darukaa.Earth Biodiversity Intelligence
Streamlit assessment application for evidence-grounded, multi-metric biodiversity reasoning.

## Deploy on Streamlit Cloud
Upload the CONTENTS of this folder to the ROOT of your GitHub repository. Do not upload the containing folder itself.
Set Main file path to `streamlit_app.py`.

## Local
`pip install -r requirements.txt`
`streamlit run streamlit_app.py`

The app works without an API key using deterministic reasoning. Optional OpenAI synthesis is enabled when `OPENAI_API_KEY` is configured.
