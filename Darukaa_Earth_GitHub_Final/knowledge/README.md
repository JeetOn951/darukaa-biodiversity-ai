# Knowledge Base

The project seeds ChromaDB from `app/data/knowledge.py`.

The initial evidence set contains sources from:
- FAO Conservation Agriculture
- FAO agroforestry materials
- FAO / Intergovernmental Technical Panel on Soils
- IPCC Special Report on Climate Change and Land
- IPBES spatial planning and connectivity assessment

For a production submission, add more peer-reviewed papers, regional datasets and structured environmental observations. Keep source title, organization, URL and evidence text with each document so every recommendation can be traced back to evidence.
